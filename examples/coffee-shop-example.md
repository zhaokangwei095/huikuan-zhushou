# 示例输出 · 咖啡店菜单与店招设计单

用户输入：给一家咖啡店做菜单设计 800、店招 1200，先收一半定金。

## 输出节选
报价草稿 BJ-20261109-01：菜单设计 ¥800 + 店招设计 ¥1,200，
合计 ¥2,000.00（人民币贰仟元整），定金 50% ¥1,000，尾款验收后 ¥1,000。
（草稿阶段页眉标注「草稿 · 待确认」）

## 交付包包含
1. 正式报价单（按 templates/quotation-template.md 生成，有效期 7 天）
2. 简易服务合同（按 templates/service-contract-template.md，含 2 次免费修改）
3. 收款确认单 ×2（定金到账、尾款到账）
4. 台账新增一行：BJ-20261109-01 / 示例咖啡店 / 应收 2000 / 已收 1000 /
   未收 1000 / 状态：待付尾款

## 金额校验（scripts/amount_check.py 实跑）
命令：python3 scripts/amount_check.py check --items 800,1200 --deposit-rate 0.5 --paid 1000
输出：合计 ¥2000.00（人民币贰仟元整）；定金 ¥1000.00；尾款 ¥1000.00；勾稽通过。
